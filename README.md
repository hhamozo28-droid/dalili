# 🎓 dalili

**تطبيق تعليمي للأساتذة — التكوين المهني**

> تقنية FastAPI + Google Gemini AI  
> واجهة عربية RTL متجاوبة — تعمل على الكمبيوتر والهاتف

---

## ✨ الميزات

### ⚡ توليد المحتوى بالذكاء الاصطناعي
- الأستاذ **يختار**: دليل أو درس
- الأستاذ **يُدخل فقط**: التخصص + المادة
- الذكاء الاصطناعي **يولّد**: العنوان + المحتوى كاملاً
- المحتوى يُخزن في قاعدة البيانات ويُعرض للأساتذة

### 🔐 نظام الدخول الآمن
- **رمز دخول مرة واحدة** — كل رمز يُستخدم مرة واحدة فقط
- الأساتذة المسجّلون يمكنهم إنشاء رموز جديدة للآخرين

### 📁 مجلدات المحتوى
- **مجلد الدليلي** — جميع الأدلة المُولَّدة
- **مجلد دروسي** — جميع الدروس المُولَّدة

### ✎️ تعديل وحذف المحتوى
- تعديل العناوين والمحتوى
- حذف محتوى غير مطلوب (مع تأكيد)

### 📊 إحصائيات
- عرض إجمالي الأدلة والدروس في اللوحة

## 🤖 الذكاء الاصطناعي

يستخدم **Google Gemini** (مجاناً) لتوليد محتوى تعليمي عالي الجودة.

### للحصول على API Key مجاني:
1. اذهب إلى [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. انقر **"Create API Key"**
3. انسخ المفتاح

### التوصيل:
1. افتح ملف `.env`
2. أدخل المفتاح:
   ```
   GEMINI_API_KEY=XXXXXXXXXXXXXXXXXXXX
   ```
3. أعد تشغيل التطبيق

> إذا لم يكن المفتاح مضبوطاً، يستخدم المولد المدمج

## 🚀 التشغيل

```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. إعداد API Key (اختياري)
cp .env.example .env

# 3. إنشاء رموز دخول أولية (اختياري)
python -m app.seed

# 4. تشغيل التطبيق
python run.py
```

ثم افتح http://localhost:8000
